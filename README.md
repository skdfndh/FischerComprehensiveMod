# Fischer Comprehensive Mod

《Fischer's Fishing Journey》（《猫猫钓游记》）的 BepInEx 5 综合模组。它为单人离线游玩提供时间倍率、日常操作自动化和成就进度查看功能。

> 本项目为非官方模组，与游戏开发商及发行平台无关联。使用前请自行备份存档，并确认符合你所在平台和游戏的使用规则。

> Mod 虽好，游戏体验更重要：建议先体验原版乐趣，再按自己的节奏选择需要的功能。

## 功能总览

- 时间管理：使用 `F6` 或面板按钮在 1 倍、2 倍、4 倍、8 倍之间切换。暂停状态不会被解除；时间倍率会同步游戏时间、商店刷新、自动采购和可加速的动作流程。
- 小猫与窝料：小猫偷懒时可自动唤醒；窝料库存大于 1 时，会连续投放并叠加持续时间，优先消耗手动购买的区域窝料，再使用原版定时恢复、上限为 5 的免费窝料。
- 鱼缸整理：一键比较鱼币收益，将更高收益的鱼放进神奇鱼缸；被替换的鱼会留在鱼篓，伙伴任务所需的鱼不会参与置换。
- 鱼群聚集：检测到小猫头上的感叹号后，自动点击进入并完成鱼群聚集小游戏。
- 伙伴交互：自动处理普通对话；伙伴提出请求时自动接取，鱼篓中材料足够便自动提交，普通闲聊也会完成。
- 鱼篓出售：鱼篓达到容量后执行一次全选出售；锁定鱼、任务鱼、当前伙伴任务所需鱼及原版自动出售设置中保留的鱼不会被出售。
- 成就进度：实时显示 Steam 成就“猫的小目标！”的累计鱼币、完成百分比和距 1 亿鱼币的剩余金额。

## 控制台

游戏左上角的“菲舍的钓鱼助手”采用暖棕、纸张和青绿色状态样式，与《猫猫钓游记》的界面氛围保持一致。点击右上角的“隐藏”后，控制台会收起；鼠标靠近左上角感应区时会显示一个小鱼按钮，点击即可重新打开。鼠标离开感应区后，小鱼按钮会自动消失。

## 安装

### 1. 安装 BepInEx 5

本模组需要 **BepInEx 5（Mono 版本）**。将 BepInEx 解压到游戏根目录；该目录应包含游戏的可执行文件。首次启动游戏后，应出现 `BepInEx` 文件夹。

### 2. 安装模组

从本仓库的 Releases 下载 `FischerTimeFlow.dll`，复制到：

```text
游戏根目录\BepInEx\plugins\FischerTimeFlow.dll
```

如果 `plugins` 文件夹不存在，请先启动一次已安装 BepInEx 的游戏，或自行创建该文件夹。

### 3. 启动并确认

启动游戏后，左上角会出现“菲舍的钓鱼助手”控制台。BepInEx 的日志文件 `BepInEx\LogOutput.log` 中应包含：

```text
Loading [Fischer 综合 Mod]
```

## 使用方法

左上角面板中的开关均会保存到 BepInEx 配置中，重启游戏后仍会保留。

| 控件 | 详细作用 |
| --- | --- |
| `切换时间倍率 (F6)` | 在 1 倍、2 倍、4 倍、8 倍之间循环切换。所有由模组同步的时间流程按所选倍率推进；暂停时不会强制恢复。 |
| `自动唤醒小猫` | 小猫进入偷懒状态时立即唤醒，避免钓鱼流程停滞。关闭后仍可在偷懒时使用面板底部的手动唤醒按钮。 |
| `自动投放窝料` | 只要有窝料库存就连续投放，多个窝料的持续时间会叠加，不需要等待前一个结束；该选项不会额外购买窝料。 |
| `整理神奇鱼缸` | 立即执行一次收益比较：更高收益的鱼进入神奇鱼缸，换下来的鱼返回鱼篓；伙伴任务所需鱼保持不动。 |
| `自动完成鱼群聚集` | 小猫头上出现鱼群聚集感叹号时，自动点击感叹号进入并完成小游戏。 |
| `自动伙伴交互` | 自动完成伙伴普通对话与闲聊、接取请求；鱼篓中满足请求材料时自动提交。仅处理当前地图的伙伴。 |
| `鱼篓满时自动出售` | 鱼篓满后按原版全选规则出售一次；锁定鱼、任务鱼、伙伴任务材料和原版自动出售保留项都受保护。 |
| `猫的小目标！` | 实时展示累计获得的鱼币、距 1 亿鱼币的完成比例及还差金额；消费鱼币不会倒扣累计进度。 |
| `隐藏` | 收起控制台。鼠标移到左上角时会出现小鱼入口，点击即可重新打开。 |
| `立即唤醒偷懒的小猫` | 仅在小猫正在偷懒时显示，点击一次立刻唤醒。 |

## 从源码构建

需要安装 .NET SDK，并准备好已安装 BepInEx 5 的游戏目录。

```powershell
git clone <仓库地址>
cd FischerComprehensiveMod
dotnet build .\FischerTimeFlow.csproj --configuration Release "-p:GameDir=游戏根目录"
```

编译成功后，DLL 位于：

```text
bin\Release\net472\FischerTimeFlow.dll
```

## 一键同步到游戏

修改源码后，**先关闭游戏**，再执行：

```powershell
.\Deploy-Game.ps1 -GameDir "游戏根目录"
```

脚本会编译、复制 DLL 到 `BepInEx\plugins` 并校验 SHA-256 哈希。需要在同步完成后启动游戏时：

```powershell
.\Deploy-Game.ps1 -GameDir "游戏根目录" -StartGame
```

## 故障排查

- 面板没有出现：确认 DLL 位于 `BepInEx\plugins`，并检查 `BepInEx\LogOutput.log` 的加载报错。
- 启动后报错：确认使用的是 Mono 版 BepInEx 5，并确认游戏更新后程序集接口没有变化。
- 同步脚本拒绝执行：请完全退出游戏和启动器后再运行脚本。
- 功能异常：关闭相应自动开关，备份存档，并附上 `BepInEx\LogOutput.log` 中与本模组相关的日志提交 Issue。
